# Границы изменений ManagerSL

Дата фиксации: 05.08.2026.

Следующие рабочие разделы считаются защищёнными. Их модели, маршруты, шаблоны и миграции нельзя удалять или перестраивать в рамках очистки и интеграции Google Sheets:

- документы: `documents`, `apps.erp_documents`;
- вузы, страны, города и программы: `catalog`, `apps.education`;
- учёт времени: `timetracking`, `apps.attendance`;
- отчёты: `reports` и связанные рабочие отчёты портала;
- пользователи и сотрудники: `users`, `apps.employees`, `apps.organizations`;
- проекты, задачи и календарь: `tasks`, `apps.projects_v2`, календарные модели и API `apps.portal`;
- напоминания о днях рождения и задачах в Celery/уведомлениях.

Интеграционный модуль может только читать справочники пользователей, городов, вузов и программ через их публичные Django-модели. Изменения этих сущностей выполняются только существующей бизнес-логикой ManagerSL.

Старые приложения нельзя физически удалять, пока не выполнены перенос данных и проверка миграций из `docs/cleanup_old_apps.md`. Допустимо скрывать архивные модели, отключать подтверждённо неиспользуемые маршруты и удалять отдельные файлы, которые не импортируются приложением.

Подтверждённо удалённый мусор:

- `test_ai.py` — отдельный интерактивный эксперимент с `g4f`;
- `test.js` — небезопасный пример внешнего запроса с зашитым API-ключом;
- `students_life/_settings.py` — неиспользуемая резервная копия старых настроек.

После удаления `test.js` ключ `LEADS_API_KEY`, ранее находившийся в Git, необходимо заменить в фактическом серверном окружении.
