# План безопасной очистки старых приложений ManagerSL

Этот документ описывает, какие старые приложения остаются в проекте временно, какие новые модули их заменяют и что нужно проверить перед отключением. Физически старые папки сейчас не удаляются: они могут быть нужны для миграций, импорта данных, старых URL и совместимости с внешним сайтом.

## Текущее правило

- В рабочей админке staff-пользователь видит актуальные ERP-разделы.
- Старые приложения скрыты от обычного staff.
- Superuser может открыть старые данные как архив, если нужно проверить миграцию или восстановить данные.
- Старый endpoint `/api/leads/create/` остаётся активным для внешнего сайта и пишет заявки в новую CRM.

## Deprecated URL

Эти URL остаются в `students_life/urls.py` временно, чтобы не сломать старые интеграции и миграцию данных:

- `/api/clients/`
- `/api/tasks/`
- старые include внутри `/api/`: `timetracking`, `reports`, `catalog`, `services`, `analytics`, `gamification`, `documents`, `users`, `notifications`, `support`

Отдельное правило:

- `/api/leads/create/` нельзя отключать без замены на внешнем сайте. Этот endpoint нужен для форм заявок и должен оставаться совместимым.

## Что мешает удалению старых приложений

1. Старые миграции могут ссылаться на модели внутри старых приложений.
2. В базе могут оставаться данные, которые ещё не перенесены в новые таблицы.
3. Внешний сайт использует `/api/leads/create/`.
4. Некоторые старые URL могут использоваться менеджерами или мобильным приложением до полного перехода.
5. Старые импорты могут оставаться в тестах, management commands или вспомогательных файлах.

## Безопасный порядок удаления

1. Скрыть старые приложения из рабочей админки. Сделано: обычный staff их не видит.
2. Проверить экспорт старых данных командой `python manage.py export_old_data`.
3. Перенести данные командой `python manage.py import_to_erp --dry-run`, затем `python manage.py import_to_erp --commit`.
4. Сравнить количество клиентов, лидов, ВУЗов, программ, услуг, сделок, платежей, задач и документов.
5. Отключить старые URL, кроме `/api/leads/create/`.
6. Прогнать `python manage.py check`, `python manage.py makemigrations --check --dry-run`, `python manage.py migrate`, `python manage.py test`.
7. Только после успешной проверки убрать старые приложения из `INSTALLED_APPS`.
8. Физическое удаление папок делать последним шагом в отдельной архивной ветке или после backup.
