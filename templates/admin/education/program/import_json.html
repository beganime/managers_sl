Импорт программ из JSON

Загрузите файл с программами. Импорт работает с новым модулем apps.education: программа сохраняется в Program, стоимость — в ProgramFee. Университет должен уже существовать в разделе “ВУЗы”.

1. Выберите JSON-файл Подходит обычный массив JSON или несколько объектов через запятую без внешних квадратных скобок.
2. Сначала проверьте Нажмите “Проверить без сохранения”. Система покажет, что будет создано, обновлено или пропущено.
3. Импортируйте в базу Если отчёт нормальный, нажмите “Импортировать в базу”. Тогда программы и цены будут сохранены.
