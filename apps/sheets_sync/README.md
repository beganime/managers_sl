# Синхронизация ManagerSL с Google Sheets

Модуль отвечает только за транспорт между ManagerSL и основной книгой учёта. Он не заменяет модели документов, учебных справочников, сотрудников, задач, календаря, рабочего времени и отчётности.

## Правила записи

- После одобрения анкеты создаётся или обновляется одна строка в листе `Общее`.
- Для каждого выбранного вуза создаётся отдельная строка в соответствующем вузовском листе.
- Поиск выполняется по `Айди`, поэтому повторный запуск обновляет строку, а не создаёт дубль.
- ManagerSL меняет только известные ему поля. Ручные поля менеджеров (почта, пароль, оплаты, статус, замечания) не очищаются.
- Справочники ответственных, городов, вузов и программ читаются из существующих моделей и записываются в лист `Справочники`.

## Настройка

Переменные перечислены в `.env.example`. JSON-ключ должен храниться вне репозитория и передаваться приложению по пути `GOOGLE_SHEETS_CREDENTIALS_FILE`.

Проверка доступа:

```console
python manage.py sync_google_sheets --check
```

Первичное заполнение:

```console
python manage.py sync_google_sheets --references --pending
```

Фоновая синхронизация выполняется Celery Beat. Ошибки и номера связанных строк сохраняются в локальной базе ManagerSL.
